# Проверка версии 0.1.0

Дата: 21 октября 2026.

- Проверены исходники интеграции Home Connect Local 1.12.5, commit `f20fecfa5918b5245793aef0041167b60359736d`.
- 19 автоматических тестов проходят: обнаружение приборов, stable unique_id, переименованные entity_id, hidden/disabled, readonly, HA availability, unknown-state buttons, сырые значения options, числовые ограничения, Remote Start, выбор устройства, отсутствие автоматических повторов, единицы времени, свет и вентилятор.
- Single-file build и синтаксис JavaScript проверены.
- В браузерном стенде проверены: программы, явное подтверждение применения, `select.select_option` с исходным option и переименованным entity_id, `switch.turn_on`, `number.set_value`, readonly, блокировка при потере связи с HA, визуальный редактор и фильтр устройств.
- Мобильная ширина: 417 px, горизонтального переполнения нет. Внешних скриптов, шрифтов и изображений нет.
- Ключи приборов и токены для карточки не нужны; имитация HA использует вымышленные сущности. Прямых подключений к бытовой технике карточка не создаёт.

Не проверено: загрузка ресурса и работа в настоящем HA пользователя, реальные реестры и состояния его Bosch SMV6ECX51E, физические команды прибора. Эти проверки требуют установки карточки на HA с доступом к технике.

Репозиторий подготовлен для HACS: `hacs.json`, сборка в `dist`, JS-файл релиза. GitHub Actions запускает тесты, проверяет актуальность сборки и валидирует репозиторий официальным HACS action. Результаты конкретного запуска доступны на вкладке Actions.
